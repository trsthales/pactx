# Decision
Implement the bidirectional `pactx update` closed-loop mutation protocol using structured ````pactx-update```` YAML fences with human-in-the-loop full-text CLI review.

# Reason
Asking an LLM with context window saturation to summarize itself causes context rot and hallucinations. The repository must ingest candidate updates and atomically update canonical state with patch semantics.
