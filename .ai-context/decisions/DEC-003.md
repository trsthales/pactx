# Decision
Enforce strict Zero-Trust defensive programming for all write operations: directory jail via `realpath`, anti-symlink/hardlink protection, markdown section injection sanitization, ReDoS-safe linear regexes, and Write-to-Temp + Atomic Rename file mutations with signal rollback.

# Reason
AI outputs are untrusted user input. Preventing arbitrary file overwrites, persistent trojaning, and corrupted partial disk states is essential for enterprise developer safety.
