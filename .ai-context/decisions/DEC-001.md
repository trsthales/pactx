# Decision
Adopt a Git-native plaintext folder structure (`.ai-context/`) with pure Markdown and YAML frontmatter instead of a proprietary cloud database or vector-only RAG.

# Reason
LLMs are stateless compute engines, while projects are persistent state. Keeping memory inside Git provides human readability, auditability, zero vendor lock-in, and instant portability across any AI model.
